FAQ

Questions this page answers

Is coding the same as remapping?

No. Coding changes supported factory settings. Remapping changes engine calibration and is handled separately as an enquiry route.

Will every hidden feature work?

No. Feature availability depends on model, year, hardware, software and BimmerCode support.

Can coded settings be reversed?

Many settings can be changed again where the module supports it, but previous coding and dealer updates can affect the route.

Want BMW or MINI hidden features enabled?

Send the feature list first so compatibility can be checked before booking.
